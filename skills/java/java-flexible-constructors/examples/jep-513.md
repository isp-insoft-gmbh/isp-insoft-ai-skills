# [JEP 513](https://openjdk.org/jeps/513) examples

Source: https://openjdk.org/jeps/513

```java
class Employee extends Person {
    Employee(String name, int age) {
        if (age < 0) throw new IllegalArgumentException("age");
        super(name, age);
    }
}
```

```java
class Sub extends Super {
    final int id;

    Sub(int id) {
        this.id = id; // same-class uninitialized field
        super();
    }
}
```
