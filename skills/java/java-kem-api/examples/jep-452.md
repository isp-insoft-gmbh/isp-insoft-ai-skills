# [JEP 452](https://openjdk.org/jeps/452) example

Source: https://openjdk.org/jeps/452

```java
KEM kem = KEM.getInstance("DHKEM");
KEM.Encapsulator enc = kem.newEncapsulator(receiverPublicKey);
KEM.Encapsulated out = enc.encapsulate();
SecretKey senderSecret = out.key();
byte[] encapsulation = out.encapsulation();

KEM.Decapsulator dec = kem.newDecapsulator(receiverPrivateKey);
SecretKey receiverSecret = dec.decapsulate(encapsulation);
```
