# [JEP 496](https://openjdk.org/jeps/496) examples

Source: https://openjdk.org/jeps/496

```java
KeyPairGenerator kpg = KeyPairGenerator.getInstance("ML-KEM");
kpg.initialize(NamedParameterSpec.ML_KEM_768);
KeyPair kp = kpg.generateKeyPair();

KEM kem = KEM.getInstance("ML-KEM");
KEM.Encapsulated enc = kem.newEncapsulator(kp.getPublic()).encapsulate();
SecretKey sender = enc.key();
SecretKey receiver = kem.newDecapsulator(kp.getPrivate()).decapsulate(enc.encapsulation());
```
