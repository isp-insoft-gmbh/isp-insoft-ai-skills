# [JEP 500](https://openjdk.org/jeps/500) examples

Source: https://openjdk.org/jeps/500

```java
class C {
    final int x;
    C() { x = 100; }
}

Field f = C.class.getDeclaredField("x");
f.setAccessible(true);
f.set(new C(), 200); // JDK 26 warns by default
```

```bash
java --illegal-final-field-mutation=debug -jar app.jar
java --illegal-final-field-mutation=deny  -jar app.jar
java --enable-final-field-mutation=com.example.serializer -jar app.jar
```
