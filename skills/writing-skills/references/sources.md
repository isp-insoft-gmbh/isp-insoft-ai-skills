# Sources of truth

- [Agent Skills specification](https://agentskills.io/specification): portable skill contract.
- Pi's installed `skills.md` at `$PI_CONTEXT_DOCS_PATH/skills.md`: current Pi discovery, loading, invocation, and validation behavior.
- [Pi skills documentation](https://github.com/earendil-works/pi/blob/main/docs/skills.md): repository fallback when installed docs are unavailable.
- [Checker scope](checker.md): local structural checker policy; its tests are the executable contract.
- [Anthropic skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices): transferable writing and evaluation guidance, not Pi runtime authority.
- [Claude Code skills](https://code.claude.com/docs/en/skills): comparison reference only; verify runtime features independently in Pi.
