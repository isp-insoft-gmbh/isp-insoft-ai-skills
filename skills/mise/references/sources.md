# Mise Sources

Use in order:

1. Installed CLI: `mise --help`, `mise <cmd> --help`.
   After inspecting config effects and trust, choose `mise doctor`, `mise config ls`, `mise ls`, or `mise tasks` diagnostics.
   Never dump environment values; see [environment safety](../SKILL.md#environment-safety).
2. LLM docs if present: <https://mise.en.dev/llms.txt>, <https://mise.en.dev/llms-full.txt>.
3. Official docs: <https://mise.en.dev/>, <https://mise.en.dev/cli/>, <https://mise.en.dev/configuration.html>, <https://mise.en.dev/schema/mise.json>.
4. Source when docs/behavior disagree: <https://github.com/jdx/mise>.
